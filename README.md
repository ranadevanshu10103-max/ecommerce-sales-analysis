# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data using Python, Pandas, and Matplotlib.

## Objectives

- Analyze product-wise sales performance
- Identify the best and lowest-selling products
- Analyze sales trends over time
- Visualize sales data using charts
- Generate meaningful business insights

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains 100 e-commerce sales records with information about date, product, quantity, price, customer ID, region, and total sales.
